# Custom Missions Fix

Fixes an issue with the [Custom Missions v1](https://f95zone.to/threads/secret-flasher-manaka-custom-missions-1-2-1-version-2-3-5.263276/) mod where missions showing in the mission list are never marked as completed.

> [!WARNING]
> Does not work with the CustomMissionsV1 emulator built into CustomMissionsV2. You **must** disable the `CustomMissions2/CM1 Emulator` script.
