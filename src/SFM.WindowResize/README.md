# Window Resize

Lets you arbitrarily resize the game window when in windowed mode. Including launch options for customizing the size and position of the window at game launch.

## Launch Options

Useful if you have a script to launch multiple instances of the game at once or frequently switch setups.

- `-x`: The x position of the window on the screen.
- `-y`: The y position of the window on the screen.
- `-w`: The width of the window.
- `-h`: The height of the window.
- `-windowed`: Forces the game to launch in windowed mode.

If you have a console window you can use `-cx`, `-cy`, `-cw`, and `-ch` to set the console window's position and size as well.

Both `-arg value` and `-arg=value` formats are supported.
