# SFM Mods

> [!CAUTION]
> **NOT SAFE FOR WORK - 18+ ONLY**

A collection of mods for Secret Flasher Manaka ([DLsite](https://www.dlsite.com/maniax/announce/=/product_id/RJ01389782.html), [f95zone](https://f95zone.to/threads/secret-flasher-manaka-v1-1-3-sheablesoft.256682/))

Originally developed by **SheableSoft**: [DLsite](https://www.dlsite.com/maniax/circle/profile/=/maker_id/RG71896.html), [Ci-en](https://ci-en.dlsite.com/creator/16553), [Twitter](https://twitter.com/sheable_soft)

## Mods

- [**CustomMissionsManager**](./src/SFM.CustomMissionsManager/): Allows you to easily manage custom missions v1 and v2 with hot reloading and a GUI.
- [**CustomMissionsFix**](./src/SFM.CustomMissionsFix/): Fixes an issue with the [Custom Missions v1](https://f95zone.to/threads/secret-flasher-manaka-custom-missions-1-2-1-version-2-3-5.263276/) mod where missions showing in the mission list are never marked as completed.
- [**WindowResize**](./src/SFM.WindowResize/): Lets you arbitrarily resize the game window when in windowed mode. Including launch options for customizing the size and position of the window at game launch.
